🧫 Protocell

Life from its molecular building blocks. Each cell's DNA is read by the real genetic code: codons → amino acids → proteins. A protein's amino-acid sequence decides what it does — a transporter that imports food, an enzyme that makes energy (ATP) or biomass, a membrane, a replicase. Those proteins run the cell's metabolism: import nutrients, build ATP and building blocks, copy the genome, divide. Mutate one base → a codon changes → an amino acid changes → a protein's job changes → the cell lives or dies. Genotype → molecules → selection.
