🧬 Tierra

One shared block of memory — the soup — filled with instructions. Every organism is a stretch of self-replicating code with its own CPU. The twist that makes this the deepest sandbox in the series: an organism can read and run code anywhere, but only write into its own offspring. So when a mutant loses its copy loop, it can survive by jumping into a neighbour's loop and replicating on borrowed machinery — a parasite. Nobody wrote parasites; they emerge, and then immunity and counter-parasites chase them. Tap the memory to read the organism living there.
