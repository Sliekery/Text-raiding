🧬 Soup

The deepest version of "DNA is code": each organism's genome is a little self-replicating program running on a virtual CPU, competing for memory and processor time. There is no fitness function — an organism survives only by copying itself before the reaper removes it. Mutations rewrite the code. Nothing about strategy is designed: faster replicators, streamlined genomes, and (given time & the right pressure) organisms that evolve to compute logic functions for an energy bonus all emerge on their own.
